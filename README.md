Information Systems graduate student at Universitas Diponegoro, with a background in Informatics Engineering (GPA 3.57). I work across analysis, data, and web systems: turning messy operational data into something a team can actually use.

- 🔬 **Research:** Thesis on an integrated DeLone & McLean, UTAUT2, and Affordance model (PLS-SEM, n = 267). Manuscript submitted to JUTIF (SINTA 2).
- ☁️ **Cloud:** Bangkit Academy x Google Cloud, Cloud Computing track.
- 🧭 **Leadership:** Chair of HMIF (82 members), covering organizational strategy and day-to-day operations.
- 🎯 **Open to:** Data analysis, data engineering, IT, project management, and operations roles.
